# LeadPilot Roadmap

## Implemented
- React/Vite landing page and inquiry form
- Demo dashboard with local browser storage
- Transparent rule-based lead scores
- Optional local Node.js proxy for n8n webhook
- GitHub Actions build workflow

## Next: demo quality
- Verify local live mode end to end with fictional test leads
- Record screen demo
- Add a clear contact/booking method and service packages
- Improve accessibility, responsiveness and dashboard usability

## Later: production features
- Secure hosted API with spam protection and rate limiting
- Persistent lead database, authenticated team dashboard
- Hosted n8n with managed secrets
- Real AI model integration with evaluation and human override
- Automated follow-up policies and consent handling

No production or AI claims should be made before those features are implemented and tested.
